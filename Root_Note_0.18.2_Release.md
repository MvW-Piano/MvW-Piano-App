# Root Note v0.18.2

## Nieuw
- **Drie tegel-iconen vervangen** door duidelijkere alternatieven uit de
  icon-library: Toonladders (oplopende toonladder-stippellijn), Intervallen
  (oor met vraagteken + pijl), Vooruit Lezen (oog met noot).
- **Akkoorden-icoon** (piano met C-E-G) gecorrigeerd naar de bijgewerkte
  versie die de gebruiker zelf heeft aangeleverd (kleine technische fout in
  de G-noot rechtgezet).

## Opgelost
- Vier tegel-iconen (Intervallen, Akkoordprogressies, Vooruit Lezen, Vrij
  Spelen) stonden nog op 256px omdat hun 512px-versie in een submap
  (`PianoICO_PC_512px/Upscaled/`) stond die over het hoofd was gezien —
  nu ook op 512px, zoals de rest van de tegels.

## Geschiedenis
- **v0.18.1** — Vaste tegelvolgorde: "Under Construction"-tegels altijd
  onderaan, Vrij Spelen daar direct vóór.
- **v0.18.0** — Volledige "Neon Pulse"-kleurstijl + nieuwe tegel-iconen uit
  een zelf aangeleverde icon-library.
- **v0.17.8 en eerder** — zie `Root_Note_DEV_0.18.2.md` voor het volledige
  overzicht.
