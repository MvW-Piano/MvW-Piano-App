# Root Note v0.17.8

## Nieuw
- **Alle tegel-iconen opnieuw ontworpen.** De vorige logo's waren op de
  tegel-achtergrond lastig te lezen — vervangen door negen nieuwe,
  zelf-getekende iconen die duidelijk laten zien wat elke oefening doet,
  allemaal in dezelfde herkenbare stijl (witte lijntekening op een
  gekleurde cirkel, zoals het icoon op de startpagina).
- **Akkoorden heeft nu ook een eigen icoon** — had er voorheen geen.

## Opgelost
- Iconen sprongen nauwelijks uit tegen de tegel-achtergrond — nu duidelijk
  zichtbaar in zowel licht als donker thema.
